Loft Concept is an interior design and construction studio in Singapore. Its website shows off finished homes and offices, and its main job is to get people to book a consultation. This line of the journal follows how that website was rebuilt and how the client was given a way to publish their own projects.

## Two phases

**Phase 1: the redesign (Saturday evening, 4 October 2026).** The old site was 25 hand-written HTML pages with the same header copied into every file, 316MB of unoptimised photos and colours that did not match the studio's Brand Guide. It was rebuilt with a [framework](glossary:framework) called [Astro](glossary:astro), so every page shares one layout and all 19 projects share one template.

**Phase 2: the client admin (that night, into 5 October).** Once rebuilt, the site was a [static site](glossary:static-site): finished pages that only a developer could change. So we added a private admin page at `loftconcept.com.sg/admin` where the client fills in a form, uploads photos and clicks Save. A robot then rebuilds the site and uploads it, and the change is live a couple of minutes later.

Each station has one job, and that separation is the main idea of the whole system:

- **The admin page** only edits files. It has no server of its own; it is a single page that runs in the browser.
- **[GitHub](glossary:github)** stores every file and remembers every change as a [commit](glossary:commit), so anything can be undone.
- **[GitHub Actions](glossary:github-actions)** is the robot. Each time something changes, it runs the tests, [builds](glossary:build) the site and uploads it.
- **Vodien** is the [hosting](glossary:hosting) company. It serves the finished files to visitors and never runs any of our code.
- **The [Cloudflare Worker](glossary:cloudflare-worker)** exists only to make "Sign in with GitHub" work safely.

## Why it was built this way

A different design could have made changes appear instantly, like WordPress does, by building every page fresh from a database each time someone visits. We chose not to, and you approved that trade-off in our conversation:

- **Fast and safe.** Visitors get ready-made files. There is no database to hack and no server code to keep patched.
- **Free to run.** GitHub, GitHub Actions and the Cloudflare Worker all fit in free plans; Vodien was already paid for.
- **Every change is recorded.** Because the admin saves to GitHub, every edit the client makes can be seen and reversed.
- **The cost is a short delay.** A change takes a minute or two to go live, because the site has to be rebuilt.
